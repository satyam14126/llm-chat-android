ENHANCED FILES
=================================================================

1. UI/Theme System
   - app/src/main/java/com/llmchat/app/ui/theme/Theme.kt
     * Added 4 new color themes (Ocean, Forest, Sunset)
     * Each theme has light and dark variants
     * ThemeMode enum for theme selection

2. UI Components
   - app/src/main/java/com/llmchat/app/ui/chat/MessageBubble.kt
     * Enhanced with code block highlighting
     * Better shadows and animations
     * Improved message actions styling
   
   - app/src/main/java/com/llmchat/app/ui/common/EnhancedComponents.kt (NEW)
     * EnhancedSearchBar - Modern search input
     * QuickReplyRow - Quick reply buttons
     * SearchResultItem - Search result cards
     * ErrorStateCard - Error display with retry
     * InfoBanner - Info/warning/success banners
     * ChipGroup - Selectable chips
     * MessageSkeleton - Loading placeholder

3. Settings & Preferences
   - app/src/main/java/com/llmchat/app/ui/settings/SettingsViewModel.kt
     * Added themeMode state management
     * Added enableAnimations preference
     * Added autoScroll preference
     * Added getDefaultProfileFlow() method
   
   - app/src/main/java/com/llmchat/app/ui/settings/SettingsScreen.kt
     * Added theme selector dropdown
     * Added animation toggle
     * Added auto-scroll toggle
     * Improved settings organization

4. Main Activity
   - app/src/main/java/com/llmchat/app/MainActivity.kt
     * Updated to pass themeMode to LLMChatTheme
     * Collects theme mode from SettingsViewModel

5. Data Layer
   - app/src/main/java/com/llmchat/app/data/repository/ProviderRepository.kt
     * Added getDefaultProfileFlow() for reactive updates
   
   - app/src/main/java/com/llmchat/app/data/local/dao/ProviderProfileDao.kt
     * Added getDefaultProfileFlow() query

6. Utilities (NEW)
   - app/src/main/java/com/llmchat/app/util/SearchUtil.kt
     * searchMessages() - Case-insensitive search
     * searchWithContext() - Search with surrounding messages
     * highlightQuery() - Highlight search terms
     * getSnippet() - Generate text snippets
   
   - app/src/main/java/com/llmchat/app/util/QuickReplyManager.kt
     * getDefaultReplies() - 10 pre-defined replies
     * getReplyById() - Get specific reply
     * getReplysByCategory() - Get replies by category
     * addCustomReply() - Add custom replies
